使用Web技术

使用Web技术,HTML CSS JavaScript可以 实现渐变、动画、高斯模糊、判断等,同 时也可以循环、控制颜色、滚动条等。
Web技术对现代浏览器的兼容性几乎为100%, 意味着您可以正常加载资源和页面。
相比PowerPoint、Scratch,HTML CSS JS有不少优点:
1.动画更丝滑流畅
2.支持很多PPT和Scratch做不到的功能和效果
3.可以快速地在浏览器中访问,不用让对方装解释器和
发送文件(需要一个发布网站的平台,比如GitHub)
4.实现一个效果和功能通常只需要几行~几十行代码
5.电脑记事本就能快速编辑,不需要复杂编译器(如果需要编辑器我推荐Visual Studio Code)
此网站通过Web技术实现图形化界面

简介

这是一个开源的网页版系统项目,托管在GitHub
主题为紫色,使用Visual Studio Code开发,有着最基础的功能:
文本编辑器、终端、设置、个性化、浏览器。
还有一些额外功能:
展示,主站
这个网页版系统项目是于2026年6月开始开发。
这个系统本身没有广告,如果看到了广告可能是第三方强制嵌入或者是第三方修改版。
现在这个网页版系统的测试版不再以Build命名,而是以Test命名,窗口显示和关闭的过 渡动画是渐显和渐隐,用的是:visibility和opacity。
